# Bibliothèque de sons (bruitages + OST)

Sons réutilisables pour toutes les vidéos de la chaîne.

## Dossiers
| Dossier | Contenu |
|---|---|
| `sfx/menace/` | grondements « ゴゴゴ », tension |
| `sfx/impact/` | coups, « dodon », révélations |
| `sfx/stand/` | invocation de Stand, auras, pouvoirs |
| `sfx/whoosh/` | transitions, swoosh, déplacements rapides |
| `sfx/horreur/` | râles, os, pas, cœur |
| `sfx/ambiance/` | portes, glitch, foule, pluie… |
| `sfx/voix/` | cris et répliques (« ORA ORA », « MUDA MUDA », « ZA WARUDO »…) |
| `sfx/jingle/` | fins, « To Be Continued », stingers |
| `ost/` | musiques et OST (une version « avec OST » séparée de la version sûre) |

## Nommage
`categorie_description_N.mp3`, par exemple `impact_dodon_1.mp3`, `voix_ora_ora_jotaro.mp3`, `ost_jojo_awaken.mp3`.
Formats acceptés : mp3, wav, ogg, m4a, flac, et aussi mp4/webm (j'extrais l'audio).

## Sources
- `*_0..3.mp3` des catégories menace/impact/stand/horreur/ambiance/jingle : générés avec ElevenLabs (text-to-sound), libres d'utilisation avec l'abonnement.
- Tout ce que tu ajoutes : note l'origine ici si possible (anime, site, création perso).

⚠️ Les sons et OST officiels de l'anime sont protégés : TikTok peut couper le son ou bloquer la vidéo. Pour chaque vidéo qui les utilise, je fais toujours aussi une version « sûre » sans eux.
