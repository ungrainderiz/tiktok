# Banque de bruitages partagée

Sons envoyés par Matt, découpés un par un (silences retirés, crête normalisée à -1 dB) pour être réutilisés
d'une vidéo à l'autre. Index machine : `index.json`. Import d'une nouvelle compilation : `tools/importer.py`.

Règles d'usage (cf. CLAUDE.md) : toujours sous la voix, à des moments justifiés par le texte ; en horreur,
privilégier les sons classés horreur / tension / impact ; les sons « meme » vont aux vidéos drôles.
« You Are My Sunshine » était muet dans la compilation : non importé.
